# 🎧 Szukacz Słuchawek SondejM

Lekka, szybka i w 100% responsywna aplikacja webowa typu PWA (Progressive Web App) zaprojektowana z myślą o jednym zadaniu: szybkim i bezproblemowym odnajdywaniu zagubionych słuchawek Bluetooth.

🔗 **Wypróbuj online (Live Demo):** [Link do GitHub Pages](https://sondejm-source.github.io/szukacz-sluchawek/)

---

## ✨ Główne funkcje

* **Wizualny i dźwiękowy radar:** Uruchamia intuicyjny interfejs ułatwiający lokalizację urządzeń.
* **Bezpieczny start:** Domyślny, bezpieczny poziom głośności (5%), aby chronić słuch i uszy podczas testów.
* **PWA (Progressive Web App):** Możliwość pełnej instalacji aplikacji bezpośrednio na ekranie głównym telefonu (Android/iOS) bez przechodzenia przez sklepy z aplikacjami.
* **Lekkość i szybkość:** Stworzona przy użyciu nowoczesnego czystego kodu oraz Tailwind CSS.
* **Licznik odwiedzin:** Wbudowany prosty licznik zlicający wejścia na stronę.

---

## 📱 Jak zainstalować na telefonie?

1. Otwórz adres aplikacji w przeglądarce mobilnej (np. Chrome).
2. Kliknij menu (trzy kropki w prawym górnym rogu).
3. Wybierz opcję **"Dodaj do ekranu głównego"** lub **"Zainstaluj aplikację"**.
4. Ikona projektu pojawi się na pulpicie Twojego telefonu jak zwykła apka!
